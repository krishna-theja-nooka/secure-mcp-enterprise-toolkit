# Gatehouse v0.1.0

Initial local portfolio release:

- Official MCP Python SDK stdio server and executable client demo.
- Bounded fleet analytics, citation-aware policy lookup, and ticket proposals.
- API-key role permissions and separate human approval through FastAPI/dashboard.
- Expiring proposals, exact-payload execution, transactional audit, replay protection.
- SQLite audit summaries, per-identity rate limiting, bounded read retries.
- Responsive dashboard, synthetic fixtures, security tests, CI and container packaging.

No paid API, cloud service, or LLM is required. This release includes an MCP server,
not an LLM chatbot or hosted production deployment. Container and GitHub publishing
checks run in your workflows; see docs/evaluation.md for local validation evidence.
