# Security policy

This is a local demonstration, not a security-certified production gateway.
See [the threat model](docs/security.md) for scope and limitations.

Do not publish API keys or real customer data in issues. For a suspected vulnerability,
use GitHub private vulnerability reporting if enabled on the repository; otherwise contact
the repository maintainer privately before sharing exploit details. Do not test against
third-party systems. Tests in this repository are limited to local synthetic fixtures.
